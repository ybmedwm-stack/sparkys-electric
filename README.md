# Sparky's Electric — Sample Site

A **fictional** sample site built by Clubhouse Apps Studio as a portfolio piece. Sparky's Electric does not exist. The reviews, address, license number, phone number, and customer names are all invented.

**Live:** https://ybmedwm-stack.github.io/sparkys-electric/

## What it demonstrates

Five-page site for a local electrician, built in the Clubhouse Apps Studio house style:

- Bold midnight-navy + electric-yellow aesthetic, distinct from the Chris Donnell Plumbing sample (premium-contractor navy + gold) so the two sites together show stylistic range
- Animated lightning hero with subtle parallax and pulse effects
- Scroll-triggered fade-ins via Intersection Observer
- Animated number counters on stats
- Glow hover states on cards and CTAs
- Circuit-pattern background overlays
- Fully responsive

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Hero, services overview, why-us split, testimonials, service area, CTA |
| `services.html` | Eight detailed service blocks |
| `about.html` | Company story, animated stat counters, credentials grid |
| `reviews.html` | Review summary card + 9 testimonial cards |
| `contact.html` | Contact info, hours, request form, service area list |

Shared: `styles.css`, `script.js`.

## Stack

- HTML5 / CSS3 / vanilla JavaScript
- No build step
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)
- Unsplash stock photography
- GitHub Pages for hosting
