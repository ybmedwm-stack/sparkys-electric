Every wire, every box, every breaker.

The full catalog of what we do. If you don't see it here, call us — we probably still do it.

01

Panel upgrades & service

Federal Pacific replacements (yes, they really do still need to go). 100A to 200A upgrades. 400A for shops and big additions. Subpanels for ADUs, garages, and boathouses. Code-correct, inspected, signed off.

  • 100A / 200A / 400A service
  • Federal Pacific replacements
  • Subpanel installs
  • Meter base replacement
  • Grounding & bonding fixes
  • Whole-house surge protection
02

EV charger installation

Level 2 home chargers for Tesla, Rivian, Ford, ChargePoint, JuiceBox, Wallbox, you name it. Load calcs done properly so you can run the charger AND the dryer AND the AC without nuking a breaker.

  • Tesla Wall Connector
  • ChargePoint Home Flex
  • Wallbox Pulsar / Quasar
  • JuiceBox 40 / 80
  • Hardwire or NEMA 14-50
  • Permit + inspection handled
03

Generators & transfer switches

Whole-house standby generators with automatic transfer. Portable generator inlets for the cabin. We size, install, commission, and teach you how to run it. Maine power goes out — be ready.

  • Generac Guardian (10k–26k)
  • Kohler 14RESA / 20RESA
  • Cummins QuietConnect
  • Manual transfer switches
  • Annual service plans
  • Load shedding panels
04

Smart-home & low-voltage

Lutron Caséta, RadioRA, Lighting control, Cat6 / Cat6A data drops, security pre-wire, in-wall AV. Done at the rough-in or retrofitted into finished walls when the homeowner already lives there.

  • Lutron Caséta / RadioRA
  • Cat6 / Cat6A data
  • Security & camera pre-wire
  • Whole-home audio rough-in
  • Smart switch installs
  • Door bell / video doorbell

Troubleshooting & diagnostics

The flickering light. The hot outlet. The breaker that pops "for no reason." The dead circuit nobody can find. Diagnostic visit, find the actual problem, fix it. No mystery, no guessing.

  • Phantom breaker trips
  • Hot or warm outlets
  • Flickering / dimming lights
  • Dead circuits
  • GFCI / AFCI trouble
  • Aluminum wiring inspections

Code, inspection & permits

Pre-purchase electrical inspections. Insurance claim documentation. Code corrections from a failed inspection. Town and AHJ sign-offs. Paperwork done properly, on schedule, the first time.

  • Insurance claim docs
  • Code correction work
  • Permit pull + sign-off
  • Solar / EV permit support
  • Smoke / CO compliance
